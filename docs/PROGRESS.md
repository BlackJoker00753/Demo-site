# Журнал работ

Формат: блок = законченный этап с коммитом. Последний блок описывает текущее состояние.

## Блок 1. Фундамент бэкенда (2026-09-24)

**Сделано**
- Проект на `uv` (`pyproject.toml`), пакет `horologium` в `backend/`.
- Строгая Pydantic-схема контента (`content/schema.py`), загрузчик с перекрёстной проверкой ссылок и хешем контента.
- ORM-модели SQLite, сборка базы из YAML с автоматической пересборкой при изменении контента.
- История цен (`price_snapshots`) переживает пересборку и может перекрывать цену из YAML более свежей.
- API v1: страны, бренды (средняя цена, мин/макс, фасеты-вкладки), модели с фильтрами, усложнения, калибры, поиск.
- Поиск с транслитерацией кириллицы и нечётким совпадением: «ролекс сабмаринер» находит Rolex Submariner.
- Раздача SPA с серверными мета-тегами для превью ссылок.
- CLI: `serve`, `check`, `build-db`, `prices report|refresh`.
- Провайдеры цен: JSON-LD, meta-теги, курсы ЕЦБ.
- Контент: 8 стран, 21 усложнение, 13 общих калибров, Rolex (11 моделей, 8 калибров, цены сверены с rolex.com 2026-09-24).
- Тесты: 12 шт.

**Решения**
- Jomashop закрыт Cloudflare-челленджем, rolex.com отдаёт 403 скриптам. Поэтому цены сверяются через реальный браузер и фиксируются с датой; автоматический refresh работает для сайтов с открытой разметкой.
- YAML-подводный камень: «: » внутри значения. Добавлен `scripts/yaml_autoquote.py`.

## Блок 2. Ассеты, SPA-ядро, глобус, главная и страна (2026-09-24)

**Сделано**
- `scripts/fetch_assets.py`: вендоринг Three.js 0.186, GSAP 3.15 (+ScrollTrigger), Lenis 1.3, Phosphor Icons; шрифты Cormorant Garamond, Onest, JetBrains Mono с кириллицей; текстуры NASA Blue Marble (2K и 8K) и VIIRS Black Marble; границы Natural Earth 1:50m (весь мир) и 1:10m (наши страны); ID-карта стран 4096×2048 для подсветки и пикинга; снимки Sentinel-2 cloudless (EOX, CC BY 4.0) для каждой страны.
- Дизайн-система (`css/tokens.css`): тёмная тема, палитра «холодная роскошь» (графит, сталь) и один акцент цвета люминесцентной массы `#9fe9c4`; правила радиусов, шкала z-index, easing-кривые.
- SPA-ядро без сборщика: роутер с ленивыми модулями, загрузкой данных параллельно с анимацией ухода, восстановлением скролла; плавный скролл Lenis + ScrollTrigger; API-клиент с кешем; поиск-палитра (⌘K, «/»).
- Глобус (`js/globe/`): собственный шейдер Земли (день/ночь с огнями городов, блики океана, френель), атмосфера-гало, 5200 мерцающих звёзд, границы всех стран, подсветка стран по ID-карте, пикинг, инерционное вращение, авто-вращение.
- Перелёт к стране: облёт + пикирование с наклоном «как со спутника», затемнение остальной Земли, спутниковый снимок только внутри границы (маска из геометрии 1:10m), светящаяся граница с анимацией прорисовки, пины брендов с кластеризацией близких (например, женевских), координаты под курсором.
- Главная: заголовок, стеклянный список стран (наведение поворачивает и подсвечивает страну на глобусе), статистика.
- Страница страны: стеклянная панель (история, факты, бренды со средней ценой и диапазоном, сортировка с FLIP-анимацией, города), на мобильных нижний лист.
- Сервер: порт по умолчанию 8765 (переменная `PORT`), `--reload` следит и за YAML.

**Замечания**
- Порт 8000 на машине заказчика занят другим процессом, поэтому по умолчанию 8765.
