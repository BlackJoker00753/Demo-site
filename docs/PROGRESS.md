# Журнал работ

Формат: блок = законченный этап с коммитом. Последний блок описывает текущее состояние.

## Блок 1. Фундамент бэкенда (2026-09-24)

**Сделано**
- Проект на `uv` (`pyproject.toml`), пакет `horologium` в `backend/`.
- Строгая Pydantic-схема контента (`content/schema.py`), загрузчик с перекрёстной проверкой ссылок и хешем контента.
- ORM-модели SQLite, сборка базы из YAML с автоматической пересборкой при изменении контента.
- История цен (`price_snapshots`) переживает пересборку и может перекрывать цену из YAML более свежей.
- API v1: страны, бренды (средняя цена, мин/макс, фасеты-вкладки), модели с фильтрами, усложнения, калибры, поиск.
- Поиск с транслитерацией кириллицы и нечётким совпадением: «ролекс сабмаринер» находит Rolex Submariner.
- Раздача SPA с серверными мета-тегами для превью ссылок.
- CLI: `serve`, `check`, `build-db`, `prices report|refresh`.
- Провайдеры цен: JSON-LD, meta-теги, курсы ЕЦБ.
- Контент: 8 стран, 21 усложнение, 13 общих калибров, Rolex (11 моделей, 8 калибров, цены сверены с rolex.com 2026-09-24).
- Тесты: 12 шт.

**Решения**
- Jomashop закрыт Cloudflare-челленджем, rolex.com отдаёт 403 скриптам. Поэтому цены сверяются через реальный браузер и фиксируются с датой; автоматический refresh работает для сайтов с открытой разметкой.
- YAML-подводный камень: «: » внутри значения. Добавлен `scripts/yaml_autoquote.py`.
