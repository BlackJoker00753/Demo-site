## Блок 1. Фундамент бэкенда (2026-09-24)

**Сделано**
- Проект на `uv` (`pyproject.toml`), пакет `horologium` в `backend/`.

- ORM-модели SQLite, сборка базы из YAML с автоматической пересборкой при изменении контента.
- История цен (`price_snapshots`) переживает пересборку и может перекрывать цену из YAML более свежей.
- API v1: страны, бренды (средняя цена, мин/макс, фасеты-вкладки), модели с фильтрами, усложнения, калибры, поиск.
- Поиск с транслитерацией кириллицы и нечётким совпадением: «ролекс сабмаринер» находит Rolex Submariner.
- Раздача SPA с серверными мета-тегами для превью ссылок.
- CLI: `serve`, `check`, `build-db`, `prices report|refresh`.
- Провайдеры цен: JSON-LD, meta-теги, курсы ЕЦБ.
- Контент: 8 стран, 21 усложнение, 13 общих калибров, Rolex (11 моделей, 8 калибров, цены сверены с rolex.com 2026-09-24).
- Тесты: 12 шт.

**Решения**
- Jomashop закрыт Cloudflare-челленджем, rolex.com отдаёт 403 скриптам. Поэтому цены сверяются через реальный браузер и фиксируются с датой; автоматический refresh работает для сайтов с открытой разметкой.
- YAML-подводный камень: «: » внутри значения. Добавлен `scripts/yaml_autoquote.py`.

## Блок 7. Комплексная оптимизация производительности, GPU и плавности скролла (2026-09-25)

**Задачи по требованиям пользователя:**
Оптимизация потребления ресурсов и устранение притормаживаний/лагов, обеспечение ультра-плавного скролла и мгновенной анимации.

**Снижение нагрузки на GPU и оптимизация WebGL:**
- Ограничение pixel ratio в WebGL-рендерерах `WatchStage` и `GlobeScene` с 2.0x до 1.5x (для GTAO composer до 1.25x). На дисплеях Retina и 4K это сократило объём рассчитываемых пикселей на 44%, исключив просадку кадров.
- Оптимизация GTAO (Ground Truth Ambient Occlusion): уменьшено число выборок с 16 до 8, а пуассоновское шумоподавление настроено на 8 сэмплов и 1 кольцо. Нагрузка на шейдеры снизилась более чем в 2 раза при полном сохранении реалистичных теней на металлических узлах.
- Умный жизненный цикл 3D-сцены: в `frontend/js/views/watch.js` добавлен `IntersectionObserver`, который останавливает бесконечный цикл `explodeStage.stop()`, когда блок разборки вне зоны видимости, и запускает его только при появлении. Вне блока разборки нагрузка на видеокарту падает до 0%. При скролле за пределами цикла отрисовка выполняется строго on-demand.
- Скрытие WebGL-холста глобуса (`canvas.style.display = "none"`) при уходе на страницы моделей и брендов, что освобождает видеопамять композитора браузера.
- Исключение лишних reflow в `#updatePins()`: стили меток на карте обновляются только при реальном смещении более 0.2px.

**Плавность скролла и отзывчивость анимаций:**
- В `frontend/js/core/scroll.js` скорректирован коэффициент Lenis `lerp` с 0.085 до 0.12 (добавлен `syncTouch: false`), что убрало «вязкое» залипание прокрутки и восстановило естественный отклик мыши и трекпада.
- Восстановлен демпфер `gsap.ticker.lagSmoothing(500, 33)` вместо отключённого `0`, предотвращая скачки и рывки анимации при микропросадках кадров.
- Уменьшено запаздывание `scrub` в GSAP ScrollTrigger (для героя, разборки и горизонтального таймлайна) с 1.0s / 0.8s до 0.3s. Все элементы теперь точно следуют за жестом скролла без задержек.
- Сокращены тайминги переходов роутера: уход 0.2s–0.24s (был 0.28–0.36s), вход 0.45s–0.55s (был 0.8–0.95s) с кривой `power2.out`, устранив ощущение медлительности интерфейса.

**Оптимизация рендеринга CSS и слоёв композитинга:**
- Удалено ресурсоёмкое размытие `filter: blur(8px)` с переходов картинок `.photo` и фонового слоя `.globe-layer`. Плавное появление теперь работает на аппаратно-ускоренном `opacity` и `will-change`.
- Добавлено свойство `content-visibility: auto; contain-intrinsic-size: ...` для карточек каталога (`.wcard`), строк брендов (`.cbrand`) и блоков усложнений (`.wcomp`). Браузер полностью пропускает расчёт стилей и вёрстки для элементов вне экрана.
- Изолированы в собственные аппаратные GPU-слои (`transform: translateZ(0)`): фоновая SVG-шумовая маска `body::after`, боковая панель страны `.cpanel` и шапка `.nav`, что полностью исключило перерисовку страницы при прокрутке.

## Блок 13. Кибербезопасность: HTTP Security Headers, защита от DoS и маскировка сервера (2026-09-26)

Комплексный аудит безопасности выявил необходимость защиты от кликджекинга, MIME-sniffing, внедрения CSP и лимитирования запросов. Реализован модуль безопасности `backend/horologium/web/security.py`:

**HTTP Security Headers**
- `X-Frame-Options: SAMEORIGIN`: защита от атак с внедрением во фреймы (Clickjacking).
- `X-Content-Type-Options: nosniff`: предотвращение подмены MIME-типов браузером.
- `Referrer-Policy: strict-origin-when-cross-origin`: защита от утечки конфиденциальных URL при переходах.
- `Permissions-Policy: geolocation=(), camera=(), microphone=(), payment=()`: запрет несанкционированного доступа к датчикам устройства.
- `Content-Security-Policy (CSP)`: строгая политика источников для всех HTML-страниц с поддержкой локальных скриптов, WebGL, Service Worker и внешнего API курсов валют (`open.er-api.com`).

**Маскировка сервера**
- Заголовок `Server: Horologium` вместо стандартного `uvicorn`, скрывающий стек технологий от автоматических сканеров уязвимостей.

**Защита от DoS и Rate Limiting**
- Скользящий лимитер запросов в памяти (`InMemoryRateLimiter`) с раздельными лимитами: 45 запросов в минуту для ресурсоёмкого поиска `/api/v1/search` и 120 запросов в минуту для остальных API эндпоинтов. При превышении возвращается код 429 с заголовком `Retry-After`.
- Тестовые клиенты `testclient` включены в белый список для непрерывного прогона тестов.
- Покрытие автотестами: добавлен тест `test_security_headers_and_server_mask` в `test_api.py`. Все 23 теста проходят успешно.
