# Светлая тема и читаемая мастерская

Светлая тема по умолчанию, постоянный переключатель в шапке, сохранение выбора до загрузки CSS.
Светло-серый стол в обеих темах. Геометрия, материалы и временная шкала Submariner не менялись.
В калькуляторе больше нет фиксированных 28 px для многострочных подписей: отдельные строки,
цель касания от 44 px, видимый выбор, aria-pressed и сохранение фокуса после пересчёта.

## Проверки

- `pytest.txt`: 42 passed, 1 skipped (прежний фильм), прежнее предупреждение Starlette.
- `motion.txt`: 6 проверок времени, зависимостей, обратимости и ракурсов.
- `themes.json`: Chromium 320/390/768/1440 px в обеих темах. Подписи целиком внутри кнопок,
  выбран один вариант, шапка помещается. Все варианты действительно нажаты; после пересчёта
  сохраняются выбранное состояние и клавиатурный фокус. Перезагрузка и SPA-навигация сохраняют
  тему; заблокированный localStorage не ломает переключатель. Смена темы не пересоздаёт сцену.
- Контраст основного текста в светлой теме 13,82:1, вторичного 6,28:1; на рабочем столе 12,16:1.
  Это измерения выбранных ролей текста, не автоматическое подтверждение WCAG для всего сайта.
- `site-light.txt`, `site-dark.txt`: 22 страницы × 2 ширины в каждой теме, чисто.
- `workshop-initial.json`: прогон 1440/768/390 px, раскладка, выбор, изоляция, остановка кадров,
  размонтирование, Save-Data и reduced-motion. При одновременной работе браузерных аудитов
  десктопная выборка прошла мимо короткой фазы вращения винта. Повтор сценария 1440 px
  в `workshop-desktop.json` проходит: угол 2,58 рад, осевой выход 1,09 мм, боковое смещение 0,
  звено ещё неподвижно. Мобильные проверки первого прогона без замечаний.
- `performance.txt`: CPU ×4, 12 Мбит/с, холодный заход. 398 КБ против 394 КБ в блоке 39,
  скрипты 156 КБ против 155 КБ, память JS 3 МБ; в покое 0 длинных задач. Единственный поздний
  запрос: прежнее ленивое фото 22 КБ. Новых изображений, 3D-ресурсов и фоновых циклов нет.
  SwiftShader и облачный CPU не заменяют замер FPS на физическом телефоне.
- `taste.txt`: 0 FAIL, предупреждения о синтаксисе снятия теней/blur и реальных всплывающих панелях.
  `impeccable.json`: один запуск детектора. Замечания относятся к существующим пружинным easing,
  точкам симуляторов, декоративным шкалам и прежним свечениям; новые блоки их не добавляют.

Снимки: `condition-light.png`, `condition-dark.png`, `tray-mobile-light.png`,
`tray-mobile-dark.png`, `tray-desktop.png`. Проверены также светлые страницы главной, страны,
бренда, каталога, TCO, хронографа и мирового времени. Обнаруженное переполнение длинных
управляющих подписей симуляторов устранено; шапка ограничена шириной экрана.

Навигация, формы и видимость деталей стали яснее. Стальные поверхности читаются на сером столе,
выделение варианта состояния не сливается с многострочным текстом. Каталог и учебные симуляторы
сохраняют своё содержание и характер. Объективной оценки «10 из 10» эти проверки не дают.
