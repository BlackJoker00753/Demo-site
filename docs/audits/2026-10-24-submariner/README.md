# Проверка мастерской Submariner

Версия от 24 октября 2026. Реальные снимки Chromium в 1440, 768 и 390 px; рендер в контейнере
через SwiftShader. Это проверка поведения и геометрии, не замер частоты кадров реального телефона.

| Проверка | Результат |
|---|---|
| pytest | 38 passed, 1 skipped: необязательный недорендеренный фильм |
| Обход сайта | 27 страниц × 2 ширины: чисто |
| Финальный обход Submariner и Submariner Date | 2 страницы × 2 ширины: чисто |
| Специальный прогон мастерской | 1440/768/390 px, 136 выбираемых узлов, 0 проблем |
| Проверено взаимодействием | Этапы, выбор настоящей геометрии, каталог, изоляция, возврат, сборка |
| Проверено потребление | До входа нет GLB; кадры в покое не растут; при переходе сцена освобождается |
| Особые настройки | Save-Data: загрузка только по кнопке; reduced-motion: переключение без анимации |
| Статика модели | Валидный GLB, <4 МиБ, <220 тыс. треугольников, встроенные текстуры, SHA-256 |
| Taste lint новых модулей | 0 FAIL, 0 WARN |
| Impeccable detector | 1 advisory: прежнее bounce-easing в pages.css, вне мастерской |

Файл модели: 2 954 512 байт, 166 исходных объектов, 164 469 треугольников. Названия дочерних элементов
сохраняются в GLB; 136 самостоятельных узлов доступны через сцену и каталог. Модель механизма
учебная; упрощения подписаны в интерфейсе.

Снимки: [ПК](desktop.png), [телефон](mobile.png), [осмотр баланса](part.png).

Визуальное решение: существующий графитовый мир Horologium, композиция Taste True-black flat
(seed 879659547), крупная модель как главный объект, понятные этапы, сведения по выбору.
Все три ширины просмотрены глазами. Исправлены масштабирование камеры, видимость делений безеля,
материалы, слишком долгие переходы на медленном рендерере и горизонтальное растягивание страницы TCO.

Проверка Taste всей страницы (`taste-page.json`) дополнительно даёт 6 FAIL и 10 WARN на старых
заголовках, маленьких подписях и декоративных стилях других секций. Они не объявляются исправленными
этой локальной заменой мастерской. Переходы космос–Земля и остальные модели сохранены.

`performance-before.txt` и `performance-after.txt`: лабораторные замеры с CPU ×4 и сетью 12 Мбит/с.
Первичная загрузка страницы около 390 КБ против 382 КБ, сама GLB в первый экран не входит.
После изменения во время ожидания не загружаются модули старой атласной разборки. Численные времена
зависят от нагрузки контейнера; они не доказывают ускорение на конкретном устройстве.
