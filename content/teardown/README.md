# Спецификации разборки по моделям

Здесь описано, из каких деталей состоит каждая модель и как Gemini должен их нарисовать.
Картинки генерирует Gemini 3 Pro Image (Nano Banana Pro), нарезает и собирает `scripts/teardown.py`.

- `families/<калибр>.yaml`: детали механизма. Одна семья на калибр или архитектуру
  (например, Rolex 3230, 3235, 3285 и 3255 устроены одинаково, отличается календарная часть).
  Детали с `only: [...]` есть только у перечисленных вариантов.
- `watches/<slug>.yaml`: модель. Ссылки на официальные фото (референсы для Gemini), семья и
  вариант механизма, плюс собственные «листы»: корпус, циферблат и стрелки, браслет, собранные часы.

## Формат детали

```yaml
- [ключ, "Название по-русски", "english prompt for Gemini", размер_мм, количество]
```

- `ключ`: описание детали на сайте берётся из `frontend/js/watch3d/parts-info.js`.
- `размер_мм`: наибольший размер детали в миллиметрах. По нему деталь масштабируется в сцене,
  поэтому масштаб, который выберет Gemini, не важен.
- `количество`: сколько одинаковых деталей (винты, звенья). Каждая занимает свою клетку сетки.

## Лист (plate)

Один лист = одна 4K-картинка 16:9: детали разложены сеткой по порядку списка, слева направо и
сверху вниз, на однородном светло-сером фоне. Порядок в сетке даёт название каждой детали, поэтому
Gemini не должен писать на картинке никаких подписей.

Слой детали в собранных часах (от задней крышки к стеклу) задаётся по ключу в `scripts/teardown.py`
(`LAYERS`), при необходимости переопределяется пятым элементом `{z: 7.5}`. По слоям часы
раскладываются вдоль оси в 3D.
