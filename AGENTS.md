# Памятка для ИИ-агентов

Прочитайте по порядку: `README.md` → `docs/ARCHITECTURE.md` → `docs/PROGRESS.md` (последний блок = текущее состояние) → `docs/CONTENT_GUIDE.md` или `docs/DESIGN.md` в зависимости от задачи.

## Правила проекта

- **Бэкенд только на Python** (FastAPI + SQLAlchemy + SQLite). Фронтенд без сборщика: ES-модули + import map, библиотеки лежат в `frontend/vendor/`.
- **Источник истины для контента: YAML в `content/`.** SQLite производная, её не редактируют руками и не коммитят. После правки YAML: `uv run horologium check`.
- **Цены** всегда с источником (`source`), датой проверки (`checked`) и типом (`msrp` = официальная розница, `market` = рынок/грей, `estimate` = оценка). Не выдумывайте цены: лучше `estimate` с пометкой.
- **Тексты на русском**, без длинного тире «—» в интерфейсе и контенте (стиль проекта): используйте точку, запятую или двоеточие. Двоеточие с пробелом внутри YAML-значения требует кавычек (`scripts/yaml_autoquote.py` делает это автоматически).
- **Логотипы брендов не используем**, только названия текстом (товарные знаки).
- После каждого законченного блока: `uv run pytest`, запись в `docs/PROGRESS.md`, коммит.
- **Фото моделей** в карточках и шапках: официальные студийные снимки брендов или свободные снимки с автором и лицензией. Сгенерированного 3D в справочных местах нет.
- **Разборка до детали** (`content/teardown/`, `scripts/teardown.py`, `docs/TEARDOWN_GEMINI_TASK.md`): детали генерирует Gemini 3 Pro Image по официальным фото, на сайте это подписано. Ключ Gemini только в переменной окружения `GEMINI_API_KEY`, в репозиторий не попадает. Исходные 4K-листы лежат в `teardown_src/` (в .gitignore).
